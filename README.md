# Geo-Python Coursework & Applied Geophysics Portfolio

This repository contains my independent coursework for the **Geo-Python Course** (curriculum by the University of Helsinki). As an **Applied Geophysics undergraduate at the Federal University of Technology, Minna**, I am utilizing this curriculum to bridge the gap between traditional geoscience workflows and modern computational data science.

The objective of this repository is to document my journey in mastering Python for spatial data manipulation, automation, and environmental data analysis—skills directly applicable to seismic data processing, borehole logging, and GIS workflows.

## 🛠️ Tech Stack & Skills Developed
* **Language:** Python 3
* **Environment:** JupyterLab / Jupyter Notebooks
* **Version Control:** Git & GitHub (JupyterLab Git Extension)
* **Core Libraries:** Pandas, NumPy, Matplotlib (for data tables, arrays, and visualization)
